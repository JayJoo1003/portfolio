# My First Portfolio Website

## Project Overview

As a high school student, I decided to create my first personal portfolio website using the Magic Portfolio template. This project helped me explore web development and learn how to build something that represents who I am as a student.

## Why I Chose This Project

I wanted to:

- Learn about web development and coding
- Create something to showcase my interests and achievements
- Understand how websites work
- Build something I could be proud of

## What I Used

I built this website using:

- **Next.js** - A React framework for building websites
- **React** - A JavaScript library for creating user interfaces
- **TypeScript** - JavaScript with type checking
- **Magic Portfolio Template** - A pre-built template I customized
- **Vercel** - For hosting and deploying my website

## My Learning Process

### Getting Started

When I first opened the template, I was overwhelmed by all the files. But I followed the documentation step by step and started making small changes to understand how everything worked.

### Understanding the Code Structure

The template was organized into:

- **Pages** (`/app` folder) - Different sections like About, Projects, Blog
- **Components** (`/components` folder) - Reusable pieces of the website
- **Content** (`/resources` folder) - All the text and information
- **Styling** - CSS and SCSS files for the design

### Customizing My Content

I learned to:

- Edit the `content.js` file to change all the text
- Add my own photos and information
- Modify the design colors and layout
- Create new pages for my projects

## Technical Challenges I Faced

### Learning New Concepts

- **Components**: Understanding how different parts of the website work together
- **Props**: How data gets passed between different parts
- **State**: How the website remembers information
- **Routing**: How different pages are connected

### Making Changes

- I was careful to make small changes and test them
- When something broke, I learned to read error messages
- I used Git to save my work and track changes

### Deployment

- Learning how to connect my code to Vercel
- Understanding how the website goes from my computer to the internet
- Setting up the domain and making sure everything works

## What I Accomplished

### Technical Skills

- Learned the basics of React and Next.js
- Understood how to customize a template
- Gained experience with Git version control
- Learned about website deployment and hosting

### Personal Growth

- Learned how to add metadata and images
